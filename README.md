# 营销建议 pdf 封底优化 v1.0

给已有营销建议 PDF 的每一页加上统一的品牌底栏，最终生成一份新的 PDF。底栏可以包含品牌标识、宣传文案、数字背书、官网按钮、企微码和小程序码，也支持带曲线、凸起等异形轮廓的设计。

## 准备三样东西

1. **原始 PDF**：需要添加底栏的营销资料。
2. **底栏图片**：建议提供清晰的 PNG；异形底栏需要透明背景。如果码图已经放在底栏中，可以直接沿用。
3. **按钮网址**：说明哪个按钮打开哪个网站，例如蓝色官网按钮打开 https://www.youzan.com/。

## 怎么使用

上传 PDF 和底栏图片，直接发送下面这段话：

> 使用「营销建议 pdf 封底优化 v1.0」，把这张底栏加到 PDF 的每一页。保留异形轮廓，按页面宽度等比放置，不遮挡正文和页码。蓝色官网按钮点击后打开 https://www.youzan.com/。二维码保留原图。先给我看真实整页效果，最终输出完整 PDF。

想调整大小、间距、颜色或按钮网址，直接说明要改哪里即可。也可以先看一篇的效果，满意后让其他 PDF 沿用同一套样式。

## 最后会得到什么

- 一份每页带品牌底栏的新 PDF，保留原文件。
- PDF 中可以点击的官网按钮。
- 真实 PDF 的整页截图，方便检查整体效果。

原稿正文保持原有尺寸，已有文字与链接尽量保留；异形凸起会预留空间，避免压住正文和页码。底栏按图片比例放置，具体位置会结合原稿适配。

## 两个小提醒

- **在 PDF 里点击按钮**；预览截图只是图片，不能点击跳转。
- **使用真实码图**。企微码、小程序码沿用你提供的原图，不生成假码；小程序码请用微信“扫一扫”检查。未提供码图时，会保留明确的待替换位置。

数字背书、电话和认证文案使用你确认的内容；更换素材时，一并核对这些信息是否仍然有效。

## 安装到 Codex

下载这个仓库，把整个文件夹重命名为 `pdf-brand-footer`，放到 `~/.agents/skills/` 目录中。Codex 会自动发现；如果没有出现，再重启 Codex。显示名称是「营销建议 pdf 封底优化 v1.0」，也可以用 `$pdf-brand-footer` 调用。目录位置参考 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

运行辅助脚本需要 Python 3.10 或以上版本。在仓库目录安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

想直接使用脚本时，可选择现成的分栏样式：

```bash
python3 scripts/add_footer.py --input /path/to/source.pdf --output /path/to/new-output.pdf --config assets/preset-columns.json
```

脚本支持三种现成排版和文件夹批量处理。**整张透明异形 PNG 由 Codex 按素材适配、合成并设置按钮点击区，脚本不会自动识别异形图片或按钮。** 图片中的文字和码图会原样保留；需要修改时请提供更新后的素材。

更多配置见 [配置说明](references/config-schema.md)。仓库只包含 skill 和辅助资源，不包含业务 PDF、私人企微码或小程序码。包内有赞 Logo 来自公开官网，品牌素材权利属于原权利人；数字背书和咨询电话是带核验日期的示例，正式使用前请更新确认。
